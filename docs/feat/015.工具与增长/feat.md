## 业务流程

### 免费工具漏斗(用户视角)

1. 搜索引擎命中工具页(工具名即搜索词,如 merge csv files online)。
2. 用户在页面完成工具功能(纯前端,不上传数据)。
3. 页内 CTA 引导安装插件 / 注册 Online(带 utm 归因)。

### 内容矩阵(运营视角)

1. 对比页:竞品名即搜索词,逐篇「竞品 X vs 我方」结构化对比(功能/价格/额度表)。
2. 教程文:「how to extract X from Google Maps」类长文,文内嵌产品 CTA。
3. 全部文章进 sitemap 与 llms.txt;多语言随 010 基建分批铺。

### 联盟计划(暂不做,以下为已调研竞品口径,启动时启用)

1. 注册联盟账号 → 获得追踪链接 → 用户经链接注册/付费 → 按结算口径分成(竞品:25% 循环佣金,客户存续期持续抽成)。
2. 竞品用独立第三方联盟平台(Become an Affiliate 注册 + Affiliate Log-in);门户内部报表/结算口径需注册后调研。

## 异常流程

- 工具执行失败(输入非法/前端异常):输入区就地报错并可重试;不采集任何用户数据,失败不影响页面其余部分。
- 对比页/教程文数据过期(竞品改价改套餐):页面标注核实日期;发现过期走内容运营更新,不自动下线。
- 多语言页缺失:未翻译语言不生成对应路由(构建期兜底),回退英文;不出现 404 死链。
- 联盟归因失败(追踪链接参数丢失/用户清 cookie):按最后一次有效点击归因,无法归因不计佣金;争议走人工核对,不阻塞其他伙伴结算。
- 文章/工具页 404(被合并或退役):进 Cloudflare 301 清单(009 域既有机制)。
