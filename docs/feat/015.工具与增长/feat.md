## 业务流程

### 免费工具漏斗(用户视角)

1. 搜索引擎命中工具页(工具名即搜索词,如 merge csv files online)。
2. 用户在页面完成工具功能(纯前端,不上传数据;Email Checker 例外,需将邮箱提交到服务端验证)。
3. 页内收尾 CTA 引导安装插件或查看插件套餐(带 utm 归因,见「工具页模板」)。

### 内容矩阵(运营视角)

1. 对比页:竞品名即搜索词,逐篇「竞品 X vs 我方」结构化对比(功能/价格/额度表)。
2. 教程文:「how to extract X from Google Maps」类长文,文内嵌产品 CTA。
3. 全部文章进 sitemap 与 llms.txt;多语言随 010 基建分批铺。

### 联盟计划(暂不做,以下为已调研竞品口径,启动时启用)

1. 注册联盟账号 → 获得追踪链接 → 用户经链接注册/付费 → 按结算口径分成(竞品:25% 循环佣金,客户存续期持续抽成)。
2. 竞品用独立第三方联盟平台(Become an Affiliate 注册 + Affiliate Log-in);门户内部报表/结算口径需注册后调研。

## 界面与操作逻辑

### 工具页模板(统一)

自上而下:

- 首屏:工具图标与「Free tools › 工具名」面包屑、H1(= 工具名)、一句说明、工具面板;功能输入(表单,按工具而定)与结果区(复制/下载按钮)都在面板内。
- 用法区(SEO 正文):Place ID Finder 为三步用法、三种 ID 讲解与特性卡;其余工具为三节 How-to。
- 相关工具(其余 6 个工具卡)→ FAQ → 收尾 CTA:安装插件 + 查看插件套餐(均带 utm 归因);插件安装开放前,安装按钮显示 Coming soon 灰化,不可触发。
- 页脚(导航 + 免责声明)。**实态(2026-10-16 核查)**:全站页脚尚无免责声明,待补。

工具逻辑全部前端执行,无后端依赖;例外是 Email Checker 和后置的 License Generator 等与账号挂钩的工具。

Email Checker 对齐竞品,检查邮箱能否实际收信,不是只校验格式:展示总体状态、能否投递、MX 记录、域名、账号类型(普通 / 角色 / 一次性 / 免费邮箱)与是否接收任意地址。验证不用登录,每 IP 每天 5 次;明显格式错误在本地提示,不消耗次数。验证服务由 admin 配置的多个 Reoon 账号提供,admin 可查看各账号剩余额度。合同见 [Email 验证](tech-Email验证.md)。

Merge CSV 选取文件后，可逐文件勾选“第二行为译名”；默认不勾选，勾选时该行不计入输入摘要和合并数据。普通 CSV、旧 Online CSV 与新双表头 Online CSV 可以混合，合并下载文件仍只有一行由输入字段名并集组成的表头。

## 异常流程

- 工具执行失败(输入非法/前端异常):输入区就地报错并可重试;不采集任何用户数据,失败不影响页面其余部分。
- Email Checker 验证失败:超出每日次数时提示次数已用完;验证额度用完或验证服务异常时统一提示系统繁忙;用户可稍后重试。
- 对比页/教程文数据过期(竞品改价改套餐):页面标注核实日期;发现过期走内容运营更新,不自动下线。
- 多语言页缺失：未启用语言不生成入口；启用语言完整覆盖现有页面，语言切换不产生死链。
- 联盟归因失败(追踪链接参数丢失/用户清 cookie):按最后一次有效点击归因,无法归因不计佣金;争议走人工核对,不阻塞其他伙伴结算。
- 文章/工具页 404(被合并或退役):进 Cloudflare 301 清单(009 域既有机制)。

## 非功能性需求

- 工具页与文章页为纯静态(Astro SSG),无客户端重逻辑;Lighthouse 性能不低于主站标准。
- 多语言：英语为默认语言，各语言共享产品事实与权限边界，覆盖营销页、工具、Dashboard、登录、授权与支付回跳的完整文案。语言切换保留来源与授权上下文，站内入口保持当前语言；启用语言及路由规则见[网站 README](../../../website/README.md#语言与路由)。
- 公开内容进入多语言 sitemap；工作区、支付回跳、授权页及已退役路由不参与索引。
