# 官网直装与 PayPal 单次购买

> 2026-10-20。本地交付验收记录，生产部署与真实资金付款另行验证。

## 交付

- 官网插件安装与购买入口启用；商店占位移除，下载 Chromium / Firefox 独立 ZIP。分发合同见 [插件需求](../../013.Maps插件/feat.md#官网分发)，竞品证据见 [直装调研](../../013.Maps插件/references/官网直装调研.md)。
- 网站与下载包共用环境配置，测试使用 `.env.test`，生产使用 `.env.production`。构建入口为 `website/scripts/build.mjs`，操作说明见 [网站 README](../../../../website/README.md#环境与官网下载)。
- 三条产品线均为 PayPal 单次自然月商品；商品播种关闭同批商品的其他渠道价，保留历史数据。合同见 [订阅系统](../../006.订阅系统/feat.md)。
- PayPal 回跳增加登录用户的服务端收款确认，支持内网后端完成订单履约。权限、渠道付款核验与幂等边界见 [支付与履约 §1.7](../../004.订单系统/tech-支付与履约.md#17-paypal-回跳展示页)。
- 复用 Atlas 的 ZIP 下载卡、安装步骤与既有结账弹窗，本轮未发现需要新增设计的界面。
- `ExtensionInstall.astro` 安装区替换为 7 张 MapsGrab 真实截图（Chromium 4 步、Firefox 3 步），可点击查看大图。素材位于 `website/public/img/install/`，仅裁剪并压缩为 WebP；同步修正 Firefox 下载包与 Chrome 开发者模式位置文案。
