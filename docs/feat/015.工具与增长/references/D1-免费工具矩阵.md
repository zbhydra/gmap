# D1 · 免费工具矩阵(竞品调研初版)

> Roadmap:D1 · 调研:🔍(清单 + 代表工具交互已核实;逐个工具正文待阶段 4)

## 代表工具交互(2026-08-30 官网抓取)

- **Email Checker**(`/email-checker`):单邮箱输入(placeholder `name@example.com`)+ Verify Email 按钮;SMTP 校验科普长文(SEO 正文),特性宣传投递率/退信率。
- **Merge CSV Files Online**(`/merge-csv-files-online.html`):文件上传 + Merge 按钮,纯前端合并。

## 功能定义

一组免费在线小工具(独立静态页,不登录可用),承担 SEO 关键词入口 + 潜客漏斗(工具页 → 插件/Online 转化)。

## 竞品工具清单(官方页脚全集,2026-08-30 核实)

| 工具 | 定位 |
| --- | --- |
| Place Id Finder | 查询地点的 Place ID(Maps 开发者高频需求) |
| Google Review Link Generator | 生成商家评论直链(商家运营者高频需求) |
| Email Checker | 单邮箱 SMTP 校验 |
| Convert Lat Long to DMS | 十进制度 → 度分秒 |
| Convert DMS to DD (Lat, Long) | 度分秒 → 十进制度 |
| Bulk Keywords Generator | 批量生成「关键词+地点」组合(与 Online 任务的批量关键词衔接) |
| Merge CSV Files Online | 合并多次采集的 CSV |
| License Generator | /license-generator(与付费体系直连,非公开工具) |

工具页为静态页(部分带 `.html` 后缀),与主站(服务端渲染)不同构——成本极低,单人可批量产出。全部工具无后端依赖(License Generator 除外)。

## 竞品实现逻辑(推断)

- 每个工具解决一个「Maps 数据工作流中的 5 分钟痛点」,页面即 SEO 落地页(工具名即搜索词)。
- 页内 CTA 引导安装插件/注册 Online。

## 我方落地要点

- 每个工具 0.5–1 天工作量(表单 + 纯前端逻辑 + SEO 页),Astro 静态页实现,复用 009 域 SEO 基建。
- 工具清单需按搜索量重排优先级(竞品清单 ≠ 搜索需求全集);阶段 4 启动时逐个立项。
- License Generator 属付费体系配套(归 006/007 决策后的产物),不进第一批。
