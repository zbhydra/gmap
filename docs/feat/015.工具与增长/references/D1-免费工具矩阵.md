# D1 · 免费工具矩阵(竞品调研初版)

> Roadmap:D1 · 调研:🔍浅(工具清单与定位;未逐个深挖交互)

## 功能定义

一组免费在线小工具(独立静态页,不登录可用),承担 SEO 关键词入口 + 潜客漏斗(工具页 → 插件/Online 转化)。

## 竞品工具清单(官网 /tools 与内链核实)

| 工具 | 路径 | 定位推断 |
| --- | --- | --- |
| Email Checker | /email-checker | 邮箱有效性校验;配合 Email 补全功能引流 |
| Merge CSV Files Online | /merge-csv-files-online.html | 合并多次采集的 CSV;采集用户的高频后续动作 |
| License Generator | /license-generator | license key 生成/管理(与付费体系直连,可能仅限已购用户) |
| Place ID Finder / Review Link Generator / 坐标转换 / Bulk Keywords Generator | /tools 内列举(首次首页抓取) | 围绕 Maps ID 体系与评论链接的高频开发者需求 |

工具页为静态 `.html`(部分带后缀),与主站(服务端渲染)不同构——成本极低,单人可批量产出。

## 竞品实现逻辑(推断)

- 每个工具解决一个「Maps 数据工作流中的 5 分钟痛点」,页面即 SEO 落地页(工具名即搜索词)。
- 页内 CTA 引导安装插件/注册 Online。

## 我方落地要点

- 每个工具 0.5–1 天工作量(表单 + 纯前端逻辑 + SEO 页),Astro 静态页实现,复用 009 域 SEO 基建。
- 工具清单需按搜索量重排优先级(竞品清单 ≠ 搜索需求全集);阶段 4 启动时逐个立项。
- License Generator 属付费体系配套(归 006/007 决策后的产物),不进第一批。
