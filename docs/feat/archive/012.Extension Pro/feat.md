# 012 · Extension Pro

## 功能目标

Extension Pro 是只服务 Telegram Web 的独立 Chrome 扩展。它通过浏览器 Popup 提供固定下载教程，并在 Telegram 页面内提供资源探测、单项与整消息下载、当前页面下载队列、账号信息、额度和 Unlimited 订阅入口。

Extension Pro 与主插件是两个独立产品：两者可以复用已经验证的行为结论，但产品范围、界面、技术文档、发布状态和后续演进互不约束。

## 当前状态

- 工程骨架、Manifest、页面注入、三入口工具带、探测面板、下载队列面板、个人中心、登录回流、额度检查和 Pro 站 Pricing 跳转已经实现。
- Telegram 下载内核仍落后于主插件已经验证的 A Document、Worker ready、本地立即取消、资源排重、大文件存储、统一远端配置、资源元数据和运行时日志方案；实验旁路源码已经清理，构建与启动基线仍待验证。
- 插件尚未上线。本域描述目标产品，未完成项由 `@plans/001.Extension-Pro下载内核统一与发布收口.md` 跟踪。

## 产品范围

### 包含

- Telegram Web A/K 当前聊天中的图片、视频、GIF、圆形视频、音频、语音和文件。
- A 版当前可见 Story 图片或视频。
- 普通消息、相册和 WebPage 预览中能够建立明确资源身份的媒体。
- 当前页面唯一 FIFO 下载队列，以及所有页面入口对同一队列状态的同步展示。
- 登录、退出、账号资料、剩余额度、Unlimited 状态与到期时间。
- 从额度入口打开 `website-tgd-pro` 登录页或 Unlimited Pricing。
- 从浏览器工具栏打开固定下载教程，连续滚动查看全部步骤和配图。
- 每个 Telegram 页面打开时读取一次统一远端配置，使用远端 DOM 稀疏覆盖和 OPFS 阈值。
- 亮暗主题、键盘操作、窄视口和减少动态效果偏好。

### 不包含

- Telegram 以外的网站。
- Options 页面、Popup 业务状态或独立下载历史页。
- 跨标签页队列、刷新后恢复、断点续传、暂停、手动重排或持久下载历史。
- K Story、A 侧边栏历史媒体或 Telegram 内部未在当前页面形成明确入口的资源。
- Telegram 官方下载管理器、直接导航下载 URL、File System Access 保存选择器或其它备用下载链。
- 主插件 UI、主站登录桥、主站 Pricing、主插件发布状态或旧协议兼容。

## 用户流程

### 浏览与下载

1. 用户打开 Telegram A/K，扩展读取一次 Telegram 统一远端配置；未配置或请求失败时使用包内完整默认值，然后开始扫描当前聊天。
2. 可下载媒体显示单项下载按钮；一条消息包含多个资源时，消息底部显示 `Download ALL ({count})`。
3. 用户点击任一入口后，资源进入当前页面唯一 FIFO。已经等待或下载中的同一资源不重复提交；任务结束后允许重新下载。
4. 队首先补齐当前资源的真实下载参数和文件信息，再检查额度，随后开始真实传输。
5. 下载成功、失败、额度不足或取消时，内容区按钮、探测面板和队列面板同步更新。

### 取消与重试

1. 等待中的任务可立即取消；取消后不进入额度检查，也不影响其它任务顺序。
2. 下载中的任务可取消；本地接受后立即从队列和所有页面入口移除，并开始下一项。底层 Abort 或 Worker cancel 只作为附带的尽力操作，不构成本地完成条件。
3. 取消不是失败，不显示失败 Toast。额度已经成功消耗时不退款；底层旧请求可能短暂继续或与下一项重叠。
4. 失败任务保留人工重试；重试复用同一个任务并排到队尾，不创建第二套队列。

### 登录与订阅

1. 未登录用户在个人中心点击登录，扩展在同一浏览器窗口打开 `website-tgd-pro` 专用登录页。
2. 官网通过固定 external message 信道把登录结果交给 Extension Pro；返回 Telegram 后个人中心刷新。
3. 用户可从个人中心额度区域或额度不足对话框打开 Pro Pricing。两个入口保留各自来源，网站只展示 Unlimited。
4. 退出登录尽力通知后端，然后清理扩展本地认证状态；后端请求失败不阻止本地退出。

### 查看教程

1. Extension Pro 首次安装完成后自动新建 Telegram Web A 版标签页；版本更新不触发跳转。
2. 当前标签页不是 Telegram Web 时，用户点击浏览器工具栏中的 Extension Pro 图标，扩展优先激活当前窗口最左侧的 Telegram Web 标签页；不存在时新建 A 版页面，本次不展示 Popup。
3. 当前标签页是 Telegram Web 时，用户点击图标打开固定尺寸的教程 Popup。
4. Popup 按顺序展示打开 Telegram 聊天、开始下载和查看下载进度三个步骤；正文独立纵向滚动。
5. Popup 除页面门禁外不读取账号、额度或下载队列，不改变 Telegram 页面内的面板状态。

## 页面界面

### 浏览器工具栏按钮

- 浏览器 action 仅在当前标签页是 Telegram Web 时打开固定教程 Popup；否则先激活当前窗口已有 Telegram Web 标签页，不存在时新建 A 版页面。
- 页面跳转不同时打开 Popup，也不切换 Telegram 页面内的探测面板。
- Popup 宽 400px、高 600px；品牌标题固定在顶部，教程正文独立滚动。
- 当前预留三处 16:9 教程图片区域；替换为真实图片时保持步骤结构和滚动合同不变。

### 消息内入口

- **单项按钮**：44×44px 圆形图标按钮，位于对应媒体右下区域。默认隐藏，唯一显示条件是鼠标悬停对应媒体；焦点、下载状态和设备能力不改变显隐。下载中禁用并显示状态图标。
- **整消息按钮**：消息底部 44px 高图标加文字按钮，固定显示当前消息可下载资源总数；已在运行的资源不重复提交，其余资源仍可加入队列。
- **Story 按钮**：44×44px 圆形图标按钮，随 A Story 当前可见媒体更新；关闭 Story 后移除。
- 所有按钮状态只来自当前页面权威队列，不维护组件私有下载状态。
- 页面加载与 downloading 旋转图标统一以 1000ms/圈匀速旋转；用户偏好减少动态效果时停止旋转。

### 浮动工具带

- 工具带挂在 Telegram 主聊天列原生向下箭头控件之前，按钮宽高均为 44px，间距 8px。
- 自下向上依次为“探测文件”“下载队列”“个人中心”。
- 探测按钮始终显示资源数量；队列按钮只在存在可见任务时显示任务数量；个人中心使用 Guest 或已登录状态圆点，不显示额度数字。
- 三个按钮共享一个面板，同一时间只打开一个。再次点击当前按钮、点击关闭图标、按 `Escape` 或点击插件外部均关闭面板。

### 共用面板

- 桌面宽度 480px、最高 560px；窄视口宽度不超过 360px，并在视口两侧保留至少 12px。
- 标题栏高度 48px，右侧为 44×44px 关闭图标；正文独立滚动，不让面板遮挡工具带和 Toast。
- 601px 是窄屏与桌面布局的唯一断点；面板不通过 JavaScript维护第二套响应式状态。

### 探测文件面板

- 显示 loading、empty 和资源列表三种状态。
- 每行显示 64×48px 当前资源预览；缺少或加载失败时显示资源类型图标。
- 显示最终文件名、类型、已知文件大小和音视频时长；缺失值显示本地化的未知状态，不为展示额外请求媒体。
- 每行只保留一个正式下载按钮，不显示实验入口或“下载全部”；整消息下载只属于消息内入口。

### 下载队列面板

- 按 FIFO 顺序显示当前页面任务，不建立第二份列表或历史。
- 标题右侧依次提供“清理所有下载”“清理等待队列”和关闭三个 44×44px 图标按钮；清理操作不弹确认框。
- 清理所有下载立即移除 waiting、downloading 和全部终态，活动传输在后台尽力取消；清理等待队列只移除 waiting，不影响 downloading。
- 每行显示最终文件名、状态、进度、已接收/总大小和下载速度；未知值保持未知。速度与字节使用稳定列宽和等宽数字，数值位数变化不改变传输区宽度。
- waiting 与 downloading 显示取消按钮；取消后任务立即移除，不展示中间状态；failed 显示重试和移除；quota-blocked 显示查看套餐和移除；success 允许短暂展示后自动移除。
- 操作按钮使用 44×44px 图标控件并提供本地化可访问名称。

### 个人中心

- Guest 状态显示登录动作、剩余额度和订阅状态。
- 已登录状态显示头像或首字母、姓名或邮箱、剩余额度、Unlimited 状态和到期时间，并提供退出、刷新和查看套餐。
- 身份、额度或订阅的局部请求失败只影响对应区域，用户可刷新或重新操作。

### 反馈

- 成功或失败使用单个 Toast；失败 Toast 提供重试，Toast 可关闭。
- 额度不足使用独立对话框，显示剩余额度、重置时间、关闭和查看 Unlimited；同一批额度不足只展示一次。
- 所有可见文字和可访问名称走 Extension Pro 自己的 i18n。

## 视觉与交互

- Extension Pro 保留自己的 Sora/Manrope、淡薰衣草表面、紫色命令色和粉色已登录状态语义，不继承主插件视觉。
- 亮暗主题使用同一组件和语义 token；不使用渐变、嵌套卡片或营销式大字号。
- 控件具备可见键盘焦点；图标与文字共同表达失败、额度不足和取消状态，不只依赖颜色。
- 面板显隐使用 150–200ms 透明度/颜色过渡，不缩放、不移动页面布局；减少动态效果偏好下缩短为近即时变化。

## 失败与风险边界

- 用户可继续操作优先于底层资源完美回收。页面崩溃、大量泄露或任务长期卡住属于必须处理的大问题；低概率轻微泄露、临时资源未完全清理、并发时轻微数据丢失等可通过刷新或重试修正的问题明确接受。
- 不为小问题增加等待 ACK、阻塞 FIFO、后台恢复、补偿、兼容或额外状态。防止小问题的机制如果会让用户卡住，必须删除该机制并保留可重试失败。

- DOM 配置、扫描或资源准备失败时允许当前项失败，用户刷新页面或重新点击即可；不增加备用 selector、轮询恢复或旧版兼容。
- 下载网络异常按已验证的分块路径继续当前任务；用户可取消。其它错误结束当前项，FIFO 继续。
- 临时存储不可用时从任务开始即使用内存路径；任务中途不切换第二条存储路径。
- Telegram 统一远端配置未设置或 HTTP 请求失败时使用完整包内默认值；阈值类型无效或配置同步失败时不提交候选 DOM，两端保留完整包内默认并继续启动。不发送第二次回滚 RPC，不回退旧 DOM 接口，不缓存或轮询。
- 页面关闭会终止当前页面队列；下次打开 Telegram 只清理 Extension Pro 自己遗留的临时文件，不恢复任务。
- 登录、Pricing 或埋点普通失败不导致页面扩展整体崩溃，用户可再次操作。

## 数据埋点

只保留已经存在的下载点击、成功、失败和额度不足四类生命周期记录。取消不记为失败；本次不新增 UI 曝光、面板点击或实验事件。

## 验收标准

- A/K 当前聊天、A Story、普通 Document 和 WebPage 媒体使用同一资源、队列、额度与下载合同。
- 任一正式下载入口都必须进入唯一队列；不存在绕过额度和状态同步的实验按钮或备用下载链。
- waiting 和三条正式传输路径的 active cancel 都立即从本地队列移除并推进 FIFO；底层尽力取消和迟到结果不恢复任务或记录成功/失败。
- 统一远端配置未覆盖时使用 200 MiB OPFS 默认阈值；有效覆盖生效后，达到阈值的 A progressive、K stream 和 Telegram HTTPS 下载在支持临时存储时，页面内存不随完整文件大小线性增长。
- A/K 文件名、大小、类型、时长和保存结果来自同一资源身份，不按大小或 DOM 顺序猜测其它 Document。
- 浏览器教程 Popup、消息入口、三个浮动入口、面板、对话框、Toast 和个人中心在桌面、窄视口、亮暗主题与键盘操作下可用且无重叠。
- 首次安装 Extension Pro 后自动打开 Telegram Web A 版页面；扩展更新不打开新标签页。
- Extension Pro 只与 `website-tgd-pro` 和 Pro API 配对；主插件、`website` 与 `website-shared` 不识别 Extension Pro。
- production build、实际插件启动和目标真实 Telegram 验收通过后才可进入发布收口。
