## 参考边界

参考仓库为 `/Users/hydra/Documents/work/project/cas/`，仅用于核对接入实现，不修改该仓库。

本次 OAuth 实现由 MapsGrab 充当授权服务器，向用户授权的 MCP 客户端签发、刷新及撤销令牌；MapsGrab MCP 服务作为受保护资源校验访问令牌。官网承载用户登录与授权确认。

| 参考入口（相对 cas 根目录） | 参考内容 |
| --- | --- |
| `server/src/app/api/mcp_server.py`、`server/src/app/schemas/mcp_schema.py` | MCP SDK 接入、工具 schema、请求身份、调用及协议响应 |
| `server/src/app/api/mcp_dependencies.py` | 接入凭证解析与鉴权边界 |
| `server/src/app/api/mcp_oauth.py`、`server/src/app/api/client/mcp_oauth_client.py` | OAuth 元数据、动态注册、授权确认、令牌兑换与刷新、撤销 |
| `server/src/app/services/mcp_oauth_service.py`、`server/src/app/models/mcp_oauth_*_model.py` | OAuth 授权与凭证存储 |
| `server/src/app/main.py`、`server/src/app/middleware/{cross_origin,error_handling}.py`、`server/deploy/nginx/nginx-example.conf` | 生命周期、协议路径、中间件与反向代理接线 |
| `website/src/services/mcp-oauth.ts` | 官网对接 OAuth 的接口合同 |

参考范围内的实现保持 CAS 的机制与处理方式，不擅自增减校验、异常、限流、过期、刷新、撤销或兼容行为。确需偏离时，先提交具体参考入口、拟改内容和影响，经 hydra 同意后实施。

CAS 的异步导出、积分计费、组织 / RBAC、组织审计、整套 API Key 管理、For AI 和客户端教程不属于参考范围，也不作为本项目首发的附加任务。

## 本项目业务落点

- API 的业务能力、输入输出与计量归 [Maps 云端](../feat.md) 和 [API 现有合同](../references/B2-API竞品口径.md)，采集复用本仓 Provider；不从 CAS 的导出业务推导工具或计费。
- 账号、登录、用量、订阅与支付沿用本项目所属模块。CAS 参考代码调用这些能力的地方接入本仓对应入口，不迁移 CAS 的业务体系。
- MCP 与 REST 共用本项目的采集业务入口；OAuth 确认页接入本站现有登录流程。授权边界若无法保持参考实现，按参考差异规则处理，不提前认定可以删减。
- API Key 仅按本项目实际接入需要确定，不因 CAS 存在临时 Key、长期 Key 复用等功能就一并引入。

## 官网与 Dashboard

官网以 [Atlas 定稿](../../../design/website/README.md) 为视觉和交互参考，映射到 Astro、现有 Vue 交互与 i18n。token、刻度与 lint 按 [website 设计合同](../../../references/specs/design-website.md) 收口，Dashboard 沿用既有工作区布局并使用合同基础层。

插件入口与插件购买入口灰化并提示“即将上线”，覆盖导航、首页产品入口、插件产品页、Pricing 和 Dashboard 中的相关动作。鼠标、键盘和直接访问页面均不能从相关 UI 触发安装或插件 checkout；不扩大为后端全面禁售或删除存量订阅。

Dashboard 保留 Online 创建、历史、下载和订阅管理，补齐本项目 API / MCP 接入所需的凭证、额度、连接信息及 OAuth 授权操作。页面继续复用现有登录、续期、会话和 API 请求封装；界面需求按本项目确定，不照搬 CAS 的整套 Dashboard。

官网文案、示例、可用端点与定价权益按本项目实际交付核对；法务发布待办见下文。API 工作区已接通，消费边界见 [Dashboard 合同](../../015.工具与增长/tech-用户Dashboard.md)，接口与计量归 [API、MCP 与 OAuth 技术合同](../tech-API与MCP.md)。
