## U2 · 父任务与 20 个 item 分表

### 改动

- 增加父任务 Model，存储关联只保存固定 `storage_id`；item 模型模块从一个抽象模型生成 20 个物理模型，由 `models/__init__.py` 导入并注册到 `Base.metadata`。
- item 模型模块暴露唯一的 `task_id % 20` 路由函数；创建父任务和全部 item 使用同一事务。
- 实现创建、用户列表、详情、启动恢复查询和 `report_item` 首次完成事务。
- 父任务只建立 `user_id` 与 `completed_at` 单列索引；列表按 `id DESC`，恢复查询先命中 `completed_at = 0`，再过滤 `APP_NAME`。
- 将 `RedisSettings`、配置模板与部署说明的全局默认值统一为 `db: 0`、`key_prefix: gmapsexporter`；环境隔离使用不同 Redis 实例。

### 验收

- `sync_database_schema --yes` 创建 1 张父表与 20 张 item 表，字段、注释、UK/INDEX 与技术合同一致。
- 同一任务的创建、读取和完成只访问 `task_id % 20` 对应分表。
- 重复报告同一 item 时，父任务进度和记录数只增加一次。
- 所有节点使用相同 Redis 默认前缀，不再按 `APP_NAME` 生成前缀。

## U3 · 异步执行与启动恢复

### 改动

- 增加 Online Provider；service 读取引擎、gosom 与对象存储配置并在初始化时传入，依赖固定为 `service -> provider -> utils`。
- 现有 Gmap HTTP / gosom Provider 改为接收调用方配置，删除对配置 service 的反向依赖；官网 enrichment 从 service 归入 Provider并保留现有 fail-open Redis 缓存，调用方同步改用新 owner。
- gosom handle 只包含 `job_id`；配置 service 只负责配置读写与加权选择。
- 创建事务提交后，service 按 item 直接创建后台协程并立即向 API 返回任务信息；协程把 Online Provider 的结果或异常转换为一次 `report_item`。
- 报告数据库事务失败时按技术合同有限重试；耗尽后复用 `send_feishu_alarm` 告警并结束该协程。报告成功或 CAS 幂等命中后均进入任务完成方法。
- HTTP item 调用一次 `search_places`；HTTP 出站并发只使用 Provider 已有的 `gmap_engine.concurrency`。
- gosom item 提交单关键词 job，在同一协程内每 5 秒查询一次；进程中断后重新提交。
- Online Provider 复用 enrichment Provider 按 50 条分批补全并合并结果。
- item 协程按父任务采集截止时间设置 Online Provider 调用的剩余超时，覆盖 HTTP 并发等待、取数、gosom 轮询、enrichment 和对象写入；超时、Provider 最终失败和对象存储失败都在超时范围外通过 `report_item` 按 0 条收口。
- 全部 item 收口后，原协程调用技术合同 §7.2 的任务完成方法，失败时每 5 秒重试最终计量与父任务完成操作。
- business 启动时按当前 `APP_NAME` 查询一次未完成父任务，重新启动未完成 item；items 已全部收口的父任务启动后台协程调用同一完成方法。business 关闭时取消剩余后台协程。

### 验收

- 创建接口在提交数据库并启动协程后立即返回。
- Provider 源码不再引用 `app.services`，配置全部由 service 传入。
- HTTP 成功、零结果、partial 和最终错误都能收口；partial 保留已有 CSV。
- gosom 完成时写入结果；进程重启后允许重新提交并继续收口。
- 启动恢复与并发重复执行不会重复增加父任务计数或实际用量。
- 报告写库最多尝试 3 次、间隔 5 秒，不重复采集和上传；耗尽后发送一次飞书告警，不再写失败状态，保留数据供启动恢复。
- 整个父任务从创建起 60 分钟后停止未完成采集；已完成 CSV 和记录数保留，启动恢复不延长期限。
- 最终计量失败一次后，无需重启进程即可自动完成任务，且只计量一次；采集期限不终止最终计量重试。

## U4 · Client API 与下载

### 改动

- 增加创建、列表和详情接口；创建请求只接收关键词，执行参数使用技术合同固定值；入口完成关键词档位上限、当前额度和对象配置校验。
- 增加单 item CSV 签名下载和整任务 ZIP 下载。
- ZIP 顺序下载 item 文件到独立临时目录，只把同步压缩放入线程；响应完成后删除临时目录。
- 下载入口校验当前用户的任务归属，内部错误与对象 key 不进入响应。

### 验收

- Free 与付费用户的关键词数量按当前权益限制；提交不预扣额度。
- 任务刷新后进度和可下载文件列表来自 MySQL。
- 单 item 下载文件名为 `{item_id}_{关键字}.csv`，关键字清理后为空时使用 `{item_id}.csv`；ZIP 包含全部可用 item CSV。
- 跨用户任务或 item 不可读取、签名或打包；无文件任务不能下载 ZIP。
- 切换启用项后，新任务绑定新配置，旧任务恢复和下载继续使用旧配置；删除已过期对象对应配置后，历史下载按文件不可用处理。
