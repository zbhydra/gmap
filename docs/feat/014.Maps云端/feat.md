# 014 · Maps 云端

## 功能目标

提供两种服务端 Google Maps 采集产品：面向运营与销售用户的 Online Scraper，以及面向开发者的同步 API。两者共享代理配置，分别按 Online records/月与 API requests/月计量。

## 产品范围

### Online Scraper

- 首页匿名用户可提交单关键词，只采首屏基础数据并查看最多 3 行；仅展示名称、地址、分类、评分、评论数和电话，缺值留空，不补全、不创建任务或文件、不扣账号额度。
- 匿名关键词与结果不随登录保留；登录后进入 Dashboard 的 Online Scraper，手动重新提交正式任务。预览与创建边界见 [首页预览与任务创建](tech-首页预览与任务创建.md)。
- 登录用户在 Online Scraper 按行输入关键词并提交任务，下方展示最近任务；提交成功清空输入，新任务出现在最近任务顶部，失败保留输入。完整历史在独立的 History 页面。约束读取失败时重试，不猜测免费档权限。
- 创建任务时仍可直接输入关键词；地图模式可选中心、半径与网格间距生成采样位置，默认间距为 5 km。地区模式可选择多个地区批量生成可编辑的查询词。地图仅影响搜索位置，不将结果限制在选定圆内。
- 整个任务跨关键词、网格按商家去重，仅交付和计量一次；来源保留首次提交的关键词。后续采样失败或到期时保留先前取得的基础结果。提交前展示逻辑搜索采样数与允许上限，最多 50 个采样，超限明确阻止，不静默截断；每个采样目标为 200 条，不保证达到。
- 地图与地区数据仅在用户进入对应模式后加载，普通关键词创建不加载这些资源。
- 免费用户不采集 Email 与社媒；有效 Online 订阅用户默认采集，可在提交时关闭。仅持有插件或 API 订阅不获得 Online 补全权益。
- 联系方式选项在提交时确定，整个任务及中断恢复沿用该选择；关闭时不查询联系方式缓存、不访问官网，CSV 保留对应列为空。
- 每个任务的关键词上限为 Free 2、Lite 5、Basic 10、Growth 20、Pro 50。
- 任务异步排队、采集并发布文件。历史列表展示任务编号与代表关键词（多个关键词时附其余数量）、采样数、已收口数、去重交付行数、状态、创建时间和操作；详情保留执行编号、时间、联系方式选项及逐采样结果与错误。
- 状态明确区分排队、采集中、准备文件、完成、局部结果和失败。前三种继续轮询，后三种停止；采样收口不代表采集成功。
- 每个有交付结果的任务只下载一份整任务文件，可选 CSV 或 Excel（由同一份 CSV 转换），文件名为「首个关键词-创建日期」；没有逐采样文件、ZIP、匿名分享或追加执行。合法零结果为完成且没有文件。
- Online CSV 为带 BOM 的 UTF-8，公开 37 列并包含连续行号。第一行保留固定英文列名，第二行按创建时界面语言展示列说明，第三行起才是商家数据。任务创建后的语言切换不改变导出语言；两行表头不计入记录数或额度。关闭联系方式补全仍保留对应空列，地图视口只在详情保留，不增加公开列。
- Online 按实际产出的 records 计量；提交和执行期间不预扣，当前任务允许超过剩余额度。已经 exhausted 的账号不能继续提交新任务。

### API

- Search、Reviews 与 Photos 是独立的同步接口，与 MCP 共用业务入口；不创建 Online 任务，也不写对象存储。
- Search 接受查询词、累计采集页数、语言和可选坐标偏置，可按 API 权益选择补全 Email 与社媒；Reviews 接受商家标识、翻页游标和排序方式。
- API 与 MCP 共用账号请求月额度；通过账号、参数和剩余额度检查后执行采集，Search 有效结果、Reviews 有效单页（含合法空页）及 Photos 部分交付各计一次请求，采集失败不计量。
- Photos 接受商家标识与本次数量上限，交付公开照片及实际数量、上游报告数和部分结果说明，不承诺完整相册。既有有效授权覆盖照片能力。

## Online 主流程

1. 用户登录后进入 Online Scraper 任务台。
2. 用户在多行输入框中逐行填写关键词，按权益选择是否采集 Email 与社媒，然后提交。
3. 系统立即返回任务编号，任务依次排队、采集并准备文件。
4. 各采样的 Maps 数据按任务选项补全官网联系方式；任务内按商家去重，采样已收口数与实际交付行数分别展示。
5. 任务收口为完成、局部结果或失败；正数交付在上传成功后与用量一起确认，合法零结果不产生文件和用量。
6. 用户在历史列表查看详情，并在文件可用时下载整任务 CSV 或 Excel。

## 界面与操作

| 区块 | 元素 | 行为 |
| --- | --- | --- |
| 任务创建 | 关键词、地图、地区三种输入 | 显示关键词和逻辑采样上限；空白与重复查询不重复计数 |
| 任务创建 | Email 与社媒开关 | 免费用户关闭且不可开启；有效 Online 订阅用户默认开启，可关闭；提交后固定 |
| 任务创建 | 提交按钮 | 输入为空、超过上限或当前额度耗尽时禁用；提交中显示加载状态 |
| 额度 | 已用量、总额度、重置时间 | 只展示当前月用量；创建及终态后刷新，不预留额度 |
| 最近任务 | 最新 5 条任务，字段与任务列表相同 | 任务名进入 History 并展开该任务；处理中轮询，终态停止，任务结束时提示一次 |
| 任务列表 | 任务编号与代表关键词、采样数、收口数、交付行数、状态、创建时间 | 按任务号或关键词搜索、按状态筛选；分页与手动刷新；处理中轮询，终态停止；不提供删除、取消或重跑 |
| 任务详情 | 执行编号、开始和结束时间、联系方式选项、逐采样结果 | 展示关键词、可选视口、去重后交付行数和收口或错误事实 |
| 整体下载 | CSV / Excel 下载按钮 | 仅在后端确认有文件时可用；零结果和文件不可用时明确提示 |

界面沿用主站现有工作台布局和响应式规则；具体尺寸、间距、状态色与组件落点在前端实施文档中定义，不在后端任务合同中重复。

## 失败行为

- 采集总等待期限为首次开始后的 60 分钟，重启不续期。超时或部分采样失败时保留已取得的结果，详情呈现对应错误。
- 基础商家结果优先，邮箱和社媒尽力补全，不保证抓到；补全失败保留基础行并呈现局部结果。
- 全部采集失败和文件发布失败明确展示失败；未交付的行不计量。用户可以手动新建任务重试，不自动重投。
- 合法零结果显示完成且没有文件，不伪装为采集失败或生成空文件。
- 文件不存在或过期时就地提示；签名过期可重新点击下载，已清理的对象不再恢复。

## 非功能需求

- 本人任务及下载由服务端校验归属，登录态与签名地址不形成匿名分享能力。
- 进程重启沿同次执行恢复，不能自动创建第二次采集；重复执行不重复增加进度或用量。
- 每个任务使用创建时选定的存储，切换配置只影响新任务；数据库不保存商家明细。
- 对象保留期通过存储侧生命周期规则管理；切换后保留旧存储，待旧对象过期再删除旧配置。

## 验收标准

1. Online 用户可以提交关键词任务，刷新或业务进程重启后任务继续收口。
2. 提交后异步执行；历史区分六种状态，终态停止轮询并刷新用量，详情不把采样收口误判为成功。
3. 正数交付下载一份整任务 CSV，跨关键词和网格去重；局部结果保留交付行，合法零结果完成但无文件。
4. Online 不预扣额度，按最终实际记录数幂等计量，并允许当前任务超过剩余额度。
5. Search、Reviews 与 Photos 同步交付，不创建 Online 任务；照片实际数量与返回列表一致，有效部分结果计一次请求，采集失败不扣量。
6. 沿已选存储发布结果并签发本人下载地址；他人不能读取任务或下载文件。
7. 免费用户不能通过修改提交参数获得联系方式；订阅用户关闭采集后，联系方式列为空，已有缓存也不回填。订阅在任务提交后变化不改变该任务的选择。
8. 补全失败或超时不丢失已取得的基础商家结果及已完成补全；基础取数或上传失败不计量，进程关闭不被当成补全失败交付。
9. Online CSV 保留 37 个公开列及连续行号，固定英文列名、创建语言列说明和商家数据依次从第一、第二、第三行开始；记录数与额度只统计整任务去重后的商家。
