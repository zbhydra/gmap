## 目标

同产品线未过期订阅补差升级到更高档位：一次性线（online / api）差额单走收银台；
自动续费线（maps_extension）渠道协议内换价；立即生效、到期日不变。

## 执行单元

### U1 报价与升级判定（后端）

- [ ] 档位序判定：同线内只按商品配置 `tier_rank` 判高，`display_order` 仅用于展示；补差计算（`(目标档价 - 当前档价) × 剩余占比`，两档都取订阅行当前渠道的同币种价格）。
- [ ] `GET /api/client/subscription/upgrade-quote`：可升级判定 + 实时报价合同（`available/reason/amount/...`）。
- [ ] 错误码与 i18n 文案（不可升级各 reason）。

验收：报价接口对各线有效订阅/无订阅/最高档/补差≤0 的返回正确；金额 6 位精度口径与 money 工具一致。

### U2 一次性线差额订单（后端）

- [ ] `POST /api/client/subscription/upgrade/checkout`：沿用订阅行当前渠道，服务端定价建升级订单（快照冻结
  `purpose=upgrade`/`source_product_id`/`target_product_id`/`base_expires_at`/折算输入），跳过同线拦截与客户端价比对，调 Provider 返回支付数据。
- [ ] 履约分支：`purpose=upgrade` 按源档位和 `base_expires_at` 条件更新，只换
  `product_id`，到期时间与渠道不变；条件未命中则转人工，不覆盖已变化的订阅。
- [ ] 升级订单在管理后台订单详情可见升级快照（`extra_metadata` 已有 JSON 渲染，无 admin 改动；
  列表级升级 Tag 列为可选后续，不进本计划验收）。

验收：Lite→Growth 补差支付后档位/配额立即新档、`expires_at` 不变；过期套利路径被拦截。

### U3 自动续费线渠道换价（后端）

- [ ] `POST /api/client/subscription/upgrade/confirm` 按渠道分流：
  - **ClinkBill**：update preview→confirm（`immediate=true` 立即折算扣款），渠道成功后本地同步换档
    （`product_id` 更新，`expires_at`、渠道引用、`auto_renew` 不变）。
  - **PayPal**：调 `revise` 取 approve 链接返回前端（本地不换档、无扣款）；买家批准后前端轮询，
    服务端查询 PayPal 订阅 `plan_id` 已等于目标档 `provider_sku` 时按共用逻辑同步档位。
    折算差额进 outstanding balance，下个账期随续费扣收。
- [ ] 服务端终态收敛：处理 ClinkBill `subscription.updated.plan_changed` 与 PayPal
  `BILLING.SUBSCRIPTION.UPDATED`；用渠道保存的本地首单引用定位用户与产品线，再按主键读取并核对订阅行，不新增外部 ID 索引；渠道计划 ID 必须唯一映射启用目标价。重复事件幂等，用户关闭回跳页不影响换档。
- [ ] **续费履约档位保护**：自动续费履约仅在当前本地订单号 = 回调携带的 `original_order_no`（首购单）时覆盖行内档位；
  续费/折算发票回调只推进账期事实。
- [ ] ClinkBill 换价后的 `invoice.paid` 仍用首单定位订阅；验签后通过 Clink API 核对订阅/session/首单引用与币种，记录渠道实付金额，不再核对首单或新档整月金额；折算发票 `periodEnd` 未推进时不延长账期。
- [ ] 幂等：重复 confirm 按渠道"已是目标档"幂等成功；PayPal 批准后重复 confirm 走查询确认。

验收：Maps Pro→Business——ClinkBill confirm 立即折算扣款；PayPal 经批准后换价、差额下期随续费扣收；
关闭回跳页后两渠道 Webhook 仍同步本地档位；Clink 折算发票不延长账期，下一期完整续费才推进到期时间，且不回退档位。

## 已知取舍

- 降级不做（下期自动降级是既有语义）；Telegram Stars 不参与升级。
- 并发两笔升级单都成功时第一笔成功换档，后续旧快照不覆盖当前订阅并转人工处理。
- 差额公式为账期锚点不变的折算口径：`补差 = (目标档月价 − 当前档月价) × 剩余占比`；
  一次性线使用当前订阅渠道价格，ClinkBill 自动续费线展示 preview 金额；PayPal 扣款额由渠道在下个账期折算，站点不出扣款额。
- PayPal 升级依赖买家批准（官方 revise 合同），无静默换价路径；不为此引入额外扣款 API。
