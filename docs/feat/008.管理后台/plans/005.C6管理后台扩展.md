## 3 · 契约要点

### 3.1 用户列表

`GET /api/admin/users?page=1&page_size=20&user_id=&email=&status=&created_start=&created_end=`

- `status` ∈ `normal|locked|deleted`(空 = 全部);`created_start/end` 毫秒时间戳闭开区间;`email` 模糊包含。
- 响应 `data = {rows: [{user_id, email, register_source, register_method, register_country, account_status, login_count, last_login_at, created_at}], total, page, page_size}`。
- 查询归 `user_service`(UserModel canonical owner):`user_lists` 增可选 `status/created_range` 过滤(纯 keyword 扩展,既有调用方零影响),新增 `count_users` 同过滤计数。

### 3.2 profile 升级

```json
{
  "user": { ...现有 AdminUserBasicInfo 不变... },
  "credits": { "balance": 0 },
  "subscriptions": [
    { "product_line": "maps_extension", "has_subscription": true, "expires_at": 1759000000000 }
  ],
  "usage": [
    { "product_line": "maps_extension", "ym": 202609, "used": 320, "total": 1000, "exhausted": false }
  ]
}
```

- `subscriptions` 固定四行(extension/maps_extension/maps_online/maps_api),只读 `_get_subscription_row`,无付费行 = `has_subscription:false, expires_at:null`(Free 不落库口径)。
- `usage` 固定三行(maps 三线),三门面各调 `get_usage(usage_identity(user_id, None), user_id=user_id)`;配置合同破裂抛 `PAYMENT_GATEWAY_ERROR` 维持 fail-closed 口径(三线 free 档已配,常态不触发)。
