# A3 · 照片抓取(竞品调研)

> Roadmap:A3 · 调研:🔍 完成 · 深读:scratch 逆向 03 §3.3 / 09

## 功能定义

在商家详情页抓取该商家相册照片 URL 列表(过滤街景图),独立导出。

## 用户操作(竞品)

1. place 详情页面板 "Reviews & Photos" 标签页,点 "Start Extracting Photos"。
2. 插件打开 Maps 官方照片画廊页(`google.com/maps/uv?pb=!1s{fid}&_ps_=1`),自动翻页。
3. 达上限/到底自动完成,导出图片 URL 列表。
4. 套餐上限:免费 10 / Pro 100 / Business 1,000 张/店。

## 竞品实现逻辑

- 页面激活标记:URL 参数 `lkt=LocalPoiPhotos` 时 photos scraper boot。
- **AT token**:遍历页面 `<script>`,从 `window.WIZ_global_data` 抠 `SNlM0e`(Google 页面级 XSRF token,HTML 明文存在)。
- 请求:POST `wizrpcui/_/WizRpcUi/data/batchexecute?rpcids=wTe8We`,payload 携带 lrd、翻页 token、固定图库常量;`_reqid` = 页码拼接固定后缀,模仿前端规则。
- 解析:剥壳方式同主搜索(去尾→`d` 字段→去前缀→parse);输出 photoUrl/videoUrl,**过滤 URL 含 streetview 的项**;next token + end 布尔控制翻页。
- 终止:达上限 / `end` / 不足 10 张。另有保留的旧通道 `listentityphotos`(当前未走)。
- 竞品只导出 URL,不下载二进制。

## 我方落地要点

- 与 A2 同理:协议参数走远程配置;竞品只出 URL,若我方要下载图片本体是纯 HTTP GET(lh3 公共 CDN,无需代理),作为增强项决策。
- 照片上限按套餐分档的口径与 003/006 域的套餐设计对齐。
