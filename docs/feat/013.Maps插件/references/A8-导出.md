# A8 · 导出(竞品调研)

> Roadmap:A8 · 调研:🔍 完成 · 深读:scratch 逆向 07

## 功能定义

采集结果导出为文件:三种格式(CSV 默认 / JSON / XLSX),列 = 用户勾选 ∩ 权益可用列；仅 Email / Social Medias 由订阅门控。全选时免费/匿名 34 列，Pro 36 列；另有自动导出与云端直传。

## 用户操作(竞品)

1. 采集完成后,面板按钮变为 "Export Detailed List - N (.CSV)",点击下载;括号内格式随设置实时变化。
2. 设置页可选格式(csv/json/xlsx)与字段勾选;开关 auto_download(完成后自动下载)、auto_save_to_google_drive / auto_save_to_hubspot(完成后直传)。
3. 空数据点击导出 alert 提示;写文件异常 alert 提示换格式重试。

## 竞品实现逻辑

- 导出前处理:全量按 Place Id 去重(先到先得)→ 文件名 = `G-Maps-Extractor-{条数}-{关键词}-{YYYY-MM-DD}`(关键词优先级:搜索框 > bulk 任务 kw > 响应记录的搜索词,空格转 `+`)。
- CSV:原生拼接;JSON/XLSX:SheetJS;JSON/XLSX 的 key 按驼峰化列名。
- Drive 直传:background REST multipart 上传(token 见 A10);HubSpot:云函数代理同步 companies/contacts(避免 CORS 与凭证暴露)。
- 评论/照片导出同构(A2/A3),文件名带 Reviews 标记与页面标题。

## 我方落地要点

- 手动导出、自动下载、auto_save CSV、批量强制导出及 Options 预览共用 `columns.ts` 的 `selectEnabledExportColumns`。按 usage 的有效付费套餐保留 Email / Social Medias；快照不可得按免费列处理。`exportConfig.proColumnsEnabled` 是全局 kill switch，关闭时付费套餐也剔除这两列。用户勾选不能绕过权益，其他 34 列不受此开关影响。
- XLSX 依赖(SheetJS 等)需经硬约束 #5(新增依赖须允许)评估;CSV/JSON 零依赖可先做。
- 大数据量导出在 MV3 下的内存策略(下载 API + Blob)实现期定;命名与去重规则照搬(无竞态风险)。
