# 07 · 导出与集成

## 导出入口与格式

- contentScript `download()` → `formatExtractData()` → `exportTo(arr, fields, format, filename)`
- 格式由 storage `export_data_format` 决定:`csv`(默认)/ `json` / `xlsx`;UI 按钮实时显示 "(.CSV)" 等
- 空数据 alert("No data!");写文件异常 alert 提示换格式重试

## formatExtractData(导出前处理)

1. 全量 pins **按 Place Id 去重**(先到先得)
2. 文件名:
   - 关键词优先级:`#searchboxinput` 输入框 > bulk 任务 kw > 解析器记录的搜索词;空格转 `+`
   - 最终:`G-Maps-Extractor-{去重后条数}-{关键词}-{YYYY-MM-DD}`
3. `fields` = generateFields() 结果(用户勾选 ∩ 36 列 − 免费剔除 Pro 列)

## 三种格式实现(contentScript mod_188 + mod_167)

| 格式 | 实现 | 关键参数 |
| --- | --- | --- |
| CSV | `json2csv` 的 `parse(arr, {fields, excelStrings: false, withBOM: true})` | **UTF-8 BOM**(Excel 中文兼容);不做 excel 字符串强制引号 |
| JSON | `JSON.stringify(arr)`(仅保留 fields 列,key 为驼峰化列名) | 驼峰化 = 首词小写 + 去空格 |
| XLSX | SheetJS:`aoa_to_sheet`(每行按 fields 取值成数组)→ 生成工作簿 → Blob 下载 | 列名为首行 |

下载:`new Blob([content])` + `URL.createObjectURL` + `<a download>` 触发(mod_188 内通用 `exportToFile(content, filename, ext)`)。

## 列名驼峰化规则(download 内 `_0x51a60e`)

```
"Business Leads" → 分词去空 → ["business","Leads"] → "businessLeads"
```
仅用于 json/xlsx 的 key;CSV 表头保持原始列名。

## 评论导出(rsScript `exportToFile`)

- 字段固定 11 列:Author / Review Text / Review Rating / Date / Photos / Likes / Owner Answer / Owner Answer Date / Author Profile / Author Image / Review URL
- `Review URL` 列实际填的是来源页面 URL(bulk 时为任务关键词)
- 文件名 `G-Maps-Extractor-Reviews-{页面标题}-{条数}-{日期}`;同样支持 csv/json/xlsx
- 照片导出:photos scraper `exportToFile`,输出过滤 streetview 后的图片 URL 列表,同样三格式

## Google Drive 自动同步(contentScript-main `uploadCSVToGoogleDrive` → background mod_176)

触发:`complete()` 时 `storage.google_drive && storage.auto_save_to_google_drive`。

流程:
1. formatExtractData 后在数据尾部追加 5 行(空行 ×2、`Search: {关键词}`、`Powered by G Maps Extractor`、`https://gmapsextractor.com`)——水印
2. background `saveToDrive`:
   - token 来自 `storage.google_drive.access_token`(官网集成时写入;有 refreshToken/revoke 维护)
   - `POST https://www.googleapis.com/upload/drive/v3/files?uploadType=multipart&supportsAllDrives=true`,multipart 包 metadata(JSON,文件名/文件夹)+ CSV 内容,Bearer token
   - 可建文件夹:`createFolder`/`generateFolder`/`openFolder`(按日期或关键词归档)
3. GA 埋点 `sync_to_google_drive`

## HubSpot 自动同步(contentScript-main `syncToHubspot` → background mod_187)

触发:`storage.hubspot && storage.auto_save_to_hubspot`。

- token 同样来自官网集成(onMessageExternal `integrate_hubspot`)
- 同步走云函数代理:`funcName: "hubspot_create_companies"`(及 contacts),payload 为格式化后的商家数据
- `syncTo(arr, fields, filename)` 返回同步结果

## bulk 自动下载链

1. 任务完成(auto_download=true)→ contentScript `download()` 本地落盘
2. `autoKWComplete()`:3 秒后 `KEYWORD_AUTO_COMPLETE{tabId, kw{complete:true, try+1}}`
3. background:关 tab → wait 2s → 工作器 next(队列推进;stuck 超限的跳过,未超限的重新入队)
4. rsScript/评论任务的对应链路同构(评论直接 `complete → download → autoComplete`)
