# 09 · 参数总表(时序 / 数量 / 阈值全量)

回答"多少秒采集一次、每次采集多少"等全部细节参数。每一项都标注了证据位置(模块文件可在 `readable/modules/` 对照;未复制的小模块给出 bundle 与模块号)。

## 1. 采集节奏(核心时序)

| 参数 | 值 | 何时生效 | 证据 |
| --- | --- | --- | --- |
| 滚动/采集轮询间隔 | **可选 [5, 6, 8, 9, 10] 秒,默认 8 秒**(storage 存索引 2) | 列表页每收到一批数据后,等待 N 秒再滚动加载下一批 | config-mod15 `REQUEST_INTERVALS`;background onInstalled 默认 `request_interval: 2`;contentScript-main refreshStorage |
| 滚动动画时长 | **随机 1.5 ~ 3.5 秒**(`Math.random()*2000+1500`) | 每次 scrollToNext 的 jQuery animate | contentScript-main scrollToNext |
| 滚动递归延迟 | **随机 2 ~ (interval+2) 秒**(`Math.random()*interval*1000+2000`) | 滚动后到下一次滚动的间隔 | contentScript-main scrollToNext |
| 到底判定 | feed **最后一个子 div 有文字**(长度>2)即停止 | 每轮滚动检查 | scrollToNext |
| XHR 截获时机 | **progress 事件**(不等 load),以响应以 `/*""*/` 结尾为完整性条件 | injected-hook | injected-hook.js |
| 注入 injected.js 延迟 | **100ms**(页面加载完后) | contentScript 文件尾 setTimeout | contentScript-main 尾部 |
| UI 挂载轮询 | **1000ms** 重试,直到 `[role=main]` 出现 | initUI | contentScript-main initUI |
| place 列表按钮挂载轮询 | **300ms** | updatePlaceListUI | contentScript-main |

## 8. 用户可见设置项汇总(options / dashboard 面板)

- **Duration(请求间隔)**:5/6/8/9/10 秒五档
- **Auto download**:完成后自动导出开关
- **导出格式**:CSV / JSON / XLSX
- **导出字段**:36 列勾选(免费自动剔除 12 个 Pro 列)
- **卡死重试次数**(dashboard 批量设置):默认 1
- **批量评论导出条数**(dashboard):默认 300
- 登录 / license key 输入 / 订阅(Stripe、Paddle 跳转)
- Google Drive / HubSpot 集成(官网授权后 token 回写插件)
