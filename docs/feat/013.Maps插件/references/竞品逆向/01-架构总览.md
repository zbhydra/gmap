# 01 · 架构总览

## 产品身份

- 名称:**G Maps Extractor - Google Maps Scraper**,v2.5.1,manifest v3
- 出品方:getwebooster.com(官网 gmapsextractor.com)
- 定位:商业线索(Business Leads)工具——从 Google Maps 搜索结果抓商家信息 + 评论 + 照片,导出 CSV,并挖 Email / 社交媒体链接

## manifest.json 关键事实(readable/manifest.json)

| 项 | 值 | 含义 |
| --- | --- | --- |
| permissions | `storage` `identity` `activeTab` | 本地存储、Google OAuth 登录、当前 tab |
| host_permissions | `*://*.getwebooster.com/*`、`*://*.google.com/*` | 后端通信 + Google 域 |
| content_scripts #1 | 所有 `google.*/maps/*`,注入 `jquery-3.2.1.min.js` + **contentScript.js** | Maps 主战场 |
| content_scripts #2 | 所有 `google.*/*` + `search.google.com/local/*`,注入 jquery + **rsScript.js** | 评论抓取页(search.google.com/local/reviews 也在 google 域内,所以 rsScript 实际覆盖了该页) |
| service_worker | `src/service-worker.js` | webpack 入口,实际加载 background.js + parse.min.js |
| oauth2 scopes | `userinfo.email` | 拿用户邮箱当账号 |
| externally_connectable | `https://*.gmapsextractor.com/*`、`http://localhost:3875/*` | 官网可向插件发消息(集成 Drive/HubSpot token) |
| web_accessible_resources | `src/*` 全开放 | 允许向页面注入 injected.js |

两个 content script 都 `run_at: document_end`、`all_frames: false`。注意 **manifest 里没有 injected.js**——它是 contentScript 运行时动态 `<script>` 注入的(见 02 文档"第 0 步")。

## 8 个 JS 入口的职责

全部是 **webpack 4 数组式 bundle**(约 368~398 个模块/入口),共享一份公共库(core-js 3.21.1、regenerator-runtime、parse.min.js、axios 变体、xlsx/SheetJS、uuid、babel-helper 等占了大头)。

| 文件 | 运行环境 | 真实职责 |
| --- | --- | --- |
| `service-worker.js` | SW | 仅 3KB:webpack runtime,启动时 require background.js 与 libs/parse.min.js |
| `background.js` | SW | 后端代理层:Parse Cloud 调用(cloudRun)、Google OAuth、license/isPro、find_leads/fetch_email、Drive/HubSpot token、GA4 埋点、tab 管理、批量任务调度 |
| `contentScript.js` | google.*/maps 页 | **主控制器**:注入 injected.js、监听搜索响应、解析字段、滚动加载、去重、UI 面板、导出触发;还包含 photos scraper |
| `injected.js` | Maps 页面主世界 | hook XMLHttpRequest,把 3 类响应原文通过 CustomEvent 转发给 contentScript |
| `rsScript.js` | google 域搜索页(实际用于 search.google.com/local/reviews) | 评论页控制器:主动 fetch 评论 RPC、翻页、导出评论 CSV |
| `popup.js` | 弹窗 | 登录/账号/设置入口(Vue 编译产物,主要承载 license 与导航) |
| `dashboard.js` | 扩展页 dashboard.html | 批量任务面板(Vue render 函数 + IndexedDB):关键词队列任务、评论 URL 队列任务、进度监控 |
| `options.js` | 设置页 | 导出格式(csv/json/xlsx)、导出字段勾选、请求间隔等 chrome.storage 写入 |

## 通信拓扑

```
Google Maps 页面 (https://www.google.com/maps/...)
├── injected.js          [页面主世界]  hook XHR
│     │ window.dispatchEvent(CustomEvent)
│     ▼
├── contentScript.js     [隔离世界]    解析 + UI + 滚动 + 导出
│     │ chrome.runtime.sendMessage({event, data})
│     ▼
├── background.js        [SW]         cloudRun / OAuth / quota / tab 管理
│     │ HTTPS
│     ▼
│   Parse Server  https://gmapsextractor.getwebooster.com/parse
│     └── Cloud Functions: findV3 / fetchEmail / isPro / license / getUsage / …
│
└── (点击评论/照片抓取时)
      contentScript 构造 URL,background CREATE_TAB 打开新标签:
      ├── https://search.google.com/local/reviews?placeid=…&_rs_=1  → rsScript.js 抓评论
      └── https://www.google.com/maps/uv?pb=!1s…&_ps_=1             → photos scraper 抓照片
```

消息封装(`mod_13`,所有 bundle 相同):
- 发送:`{event: <EVENT 常量>, data: <payload>}` → `chrome.runtime.sendMessage`
- 接收:`msg.on(EVENT, handler)` 包装 `chrome.runtime.onMessage.addListener`
- 事件常量全集见 `readable/modules/config-mod15.js`(AUTH/LOGIN/GET_IS_PRO/FETCH_EMAIL/FIND_LEADS/GET_PLUS_CODE/KEYWORD_AUTO_*/BULK_*/GA_EVENT 等 60+ 个)

## 持久化(chrome.storage.local,`mod_11` 封装)

| key | 内容 | 写入方 |
| --- | --- | --- |
| `license` | `{key, app}` license 密码卡 | 用户输入 |
| `request_interval` | 0~4(映射 [5,6,8,9,10] 秒) | options |
| `auto_download` | bool,完成后自动导出 | options |
| `fields` | 勾选的导出字段数组 | options |
| `export_data_format` | csv(默认)/json/xlsx | options |
| `stuck_max_retry` | 卡死重试次数,默认 1 | 安装时 |
| `google_drive` / `auto_save_to_google_drive` | OAuth token 与开关 | 官网集成流程 |
| `hubspot` / `auto_save_to_hubspot` | 同上 | 官网集成流程 |

批量任务队列存在 dashboard 的 **IndexedDB**(`getDB`,dashboard/mod_347),任务对象含 kw、try、stuck、complete、skip、reviews_max_export 等字段。

## 技术栈小结

- 混淆:obfuscator.io(字符串数组 + 十六进制命名 + 控制流),webpack 4 打包
- 运行时:jQuery 3.2.1(content script)、regenerator-runtime(async 编译)、core-js 3.21.1 polyfill、Parse JS SDK 3.x/4.x、SheetJS(xlsx)、uuid
- UI:contentScript/rsScript 用**模板字符串 + jQuery 直插 DOM**;dashboard/popup 是 Vue 2 编译后的 render 函数
- 统计:GA4 Measurement Protocol(www.google-analytics.com/mp/collect)+ 后端 event 云函数
