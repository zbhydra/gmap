## 账号体系

1. 登录(`LOGIN`):`chrome.identity.getUserInfo()`(Google OAuth,scope `userinfo.email`)→ `{email, id}`
2. `Parse.User.logIn({username: email, password: id})`,失败自动 `signUp` 同参数
   ——即 Google 账号密码即 Parse 账号密码;**没有独立注册流程**
3. Edge/非 chrome 走 `getUserInfoByWebAuthFlow()`(launchWebAuthFlow 弹窗授权)
4. 登出:清 Drive/HubSpot storage + `Parse.User.logOut()`

## 付费判定(双轨)

| 轨道 | 触发 | 云函数 | 返回 |
| --- | --- | --- | --- |
| 账号制(主) | 插件登录后 | `isPro({uid})` | `{pro: bool, plan: "free"/"pro"/"business", extension: {content: {html}, version: {v, html}}, quota…}` |
| License key(辅) | 用户在 dashboard 输入 key | `license({key, app: "GMapsExtractor"})` | `{code, license{key, app, extension…}}`,code===0 即 Pro |

- `isPro` 结果缓存于各 contentScript 实例(`this.isPro`),UI 据此隐藏 UPGRADE 按钮/剔除 Pro 字段
- `extension.content.html` 是**服务端下发的 HTML 片段**,直接 `$("#content-html").html(...)` 注入面板——作者可远程改公告/广告,无需发版
- `extension.version.v` 与本地版本 `localeCompare` 判断 `hasNewVersion`,决定是否附加 `version.html` 提示

## 用量计量

- `GET_USAGE` → `getUsage({app: "GMapsExtractor", version})` → `{usage: {month: n}, quota: {monthly: q}, resetAt}`
- `usage_percent = floor(usage.month / quota.monthly * 100)`,≥100 禁止 start() 并显示 "You have used all of your lead requests for the period ending {date}"
- 计数点:
  - 勾选 Email/Social 时,FIND_LEADS 每条调 `findV3`(服务端自然计量)
  - 未勾选时发 `COUNT_ONLY` → `findNoop({app, key, version, increment: pins.length})` **空挖但仍上报增量**——免费用户也有月 1000 的 leads 计量
- 套餐:free 1000 / pro 100,000 / business 500,000 leads/月;评论 20/250/2500;照片 10/100/1000

## 服务端代抓(核心增值,也是"后门")

| 云函数 | 入参 | 出参/作用 |
| --- | --- | --- |
| `getFindParams` | 无 | `{version, size, lookup}` 下发挖掘算法版本与分流开关(lookup==="v3" 走新版) |
| `findV3` | `{domain, profiles: Name+Fulladdress, kgmid, website, app, key, version, kw}` | `{emails: [], medias: {instagram, facebook, …}}` —— 服务端搜官网/图谱并抓邮箱社链 |
| `fetchEmail` | `{domain}` | `{result: [emails]}`(旧版仅邮箱) |
| `hubspot_create_companies/contacts` | token + 数据 | HubSpot API 代理(避免 CORS/暴露凭证) |
| `event` | `{event: "chrome_install"…}` | 行为上报 |
| `license` | `{key, app}` | license 校验 |
| `findNoop` | `{…, increment}` | 纯计数 |

含义:**Email/Social Medias 两列的可信来源在作者服务器上,客户端只是展示**。服务端可实现黑名单、计量、按 plan 限流——付费墙真正落地点。

## Google Drive / HubSpot 授权流(外部消息)

- 官网(gmapsextractor.com,在 `externally_connectable` 白名单)完成 OAuth 后:
  `chrome.runtime.sendMessage(extId, {data: JSON.stringify({event: "integrate_google_drive", token…})})`
- SW `onMessageExternal` → `drive.saveToken(...)` / `hubspot.saveToken(...)` 存入 storage
- 之后导出时可 auto save:Drive 直传(background mod_176,REST multipart);HubSpot 走云函数代理(mod_187)
- 相关模块:`background-drive.js`(saveToDrive/uploadCSVToDrive/createFolder/generateFolder/openFolder/revoke/refreshToken/saveToken)、contentScript 侧同名模块(mod_176)

## 统计
