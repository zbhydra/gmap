# A2 · 评论抓取(竞品调研)

> Roadmap:A2 · 调研:🔍 完成 · 深读:scratch 逆向 03 §3.2 / 09

## 功能定义

在某个商家详情页,抓取该商家的用户评论(11 列:作者、评分、正文、日期、图片、点赞、商家回复等),支持翻页至套餐上限,独立导出 CSV。

## 用户操作(竞品)

1. 打开任意 place 详情页(URL 含 `/place/`),插件面板多出 "Reviews & Photos" 标签页。
2. 点 "Start Extracting Reviews"。
3. 插件自动开新标签页(Google 官方评论列表页 `search.google.com/local/reviews?placeid=…`),后台自动翻页抓取。
4. 达上限/到底自动完成;用户点按钮导出(文件名 `G-Maps-Extractor-Reviews-{标题}-{条数}-{日期}`)。
5. 套餐上限:免费 20 / Pro 250 / Business 2,500 条/店;批量任务可自定义(默认 300)。

## 竞品实现逻辑

**入口解析**:从 place URL 提取十六进制 ID(正则 `0x…`,长度 ≤20),末两个拼 fid、最后一个为 lrd;`cid = BigInt(lrd) 转十进制`;fid 经后端云函数换 placeId。

**采集方式**:在官方评论页**主动 fetch**(非拦截)内部服务 `GetLocalBoqProxy`,`reqpld` 参数定位商家(lrd)、每页 10 条、带字段掩码与翻页 token。

**解析**:双解析器并存——主用文本解析(按行 split,第 3 行 JSON.parse,列表与 token 有固定下标);回退 HTML 解析(全插件唯一一处 DOM 选择器解析,`.gws-localreviews__google-review` 系)。每条评论:评分、日期+时间戳、作者名/头像/主页、点赞、正文、图片列表、商家回复+日期、评论链接。照片 URL 统一补 `=w1000` 尺寸。

**翻页与终止**:有 next token → 等 2s 递归;终止条件 = 达套餐上限 / 不足一页(10 条)/ 无 token。页面兜底:无评论图、错误容器、标题含 500 → 直接完成并通知批量调度器。

## 我方落地要点

- 协议无需登录态即可调(该页为 Google 公开页面),风险主要是 Google 改版——翻页参数与下标走远程配置通道(parseSchema 组,同 A1)。
- 翻页节奏固定 2s,拟人化程度低于主搜索,复刻时建议同样纳入 scrape 组远程参数。
- 批量评论 URL 队列(A6)与本功能共用采集逻辑,仅调度入口不同。
