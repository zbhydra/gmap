# A1 · 地图搜索抓取(竞品调研)

> Roadmap:A1 · 调研:🔍 完成(含 Playwright 实测)· 深读:scratch 逆向 02/03/05/10,黄金样本 `golden-samples/`

## 功能定义

用户在 Google Maps 搜索后,插件采集当前搜索结果列表中的商家数据(36 列,见 A5),自动滚动加载全部结果,采集过程实时展示计数,完成后导出。

## 用户操作(竞品)

1. 安装插件并登录(dashboard/popup,Google OAuth;**我方已拍板不强制登录**,见 A11)。
2. 打开 `google.com/maps` 任意搜索结果页,页面左侧出现插件面板(#map_scraper)。
3. 在 Maps 正常输入关键词搜索。
4. 点面板 Start Extracting → 面板进入采集中状态(显示已采集条数、Pause 按钮)。
5. 插件自动滚动结果列表加载更多;到底或达上限自动完成。
6. 完成后点 Export Detailed List - N (.CSV) 导出(或开启 auto_download 自动下载)。
7. 单次上限:免费 10 条,付费受月配额管(99999 条/次)。

## 竞品实现逻辑

**采集原理**:不解析 DOM,拦截 Maps 页面自己发出的内部 RPC 响应(`/search?tbm=map`):

- injected.js 注入页面主世界 hook `XMLHttpRequest`,在 progress 事件即截获响应(以 `/*""*/` 结尾判完整),CustomEvent 转发给 contentScript。
- 响应剥壳:去尾部哨兵 6 字符 → 取 `d` 字符串 → 去 `)]}'` 前缀 → JSON.parse → **商家列表在倒数第 8 个元素**;两种响应形态(格式 A 直接导航 / 格式 B SPA XHR)并存,竞品只处理 B,复刻需两者兼容(实测报告结论二)。
- 解析:详情数组按固定下标取 36 字段(下标表见 A5;实测 20/20 命中,协议 100% 有效)。
- 去重:解析时按 Cid+Name,导出时按 Place Id。

**滚动驱动**:找 `div[role=feed]` 容器,jQuery animate 滚到底(动画随机 1.5–3.5s 拟人),Maps 每次滚到底发起新一批 XHR,形成「滚动→拦截→等待 interval 秒(默认 8s,可调 5–10s)→再滚动」闭环。feed 末项出现文字提示(如 "You've reached the end")即终止;结果 <2 条直接完成。

**特殊模式**:
- drag 模式(「结果随地图移动」开启):不滚动,被动收集地图移动产生的响应;批量模式会自动关掉该开关。
- place 列表模式(Google 搜索侧栏本地结果):给每项插 Extract 按钮,逐项打开详情采集。

**付费墙**:免费超 10 条截断;每次 start 前查用量百分比 ≥100% 弹订阅页;勾 Email/Social 每条上报服务端计量,未勾发 COUNT_ONLY 空挖计数(免费也有月 1000 计量)。

## 我方落地要点(已拍板,scratch 11 号)

- **不照抄 DOM 选择器**:`#searchboxinput` 已死(现为 `div[role=search] input#ucc-1[name=q]`,竞品实测静默失败)。关键词不读 DOM(响应剥壳后首元素即查询词,URL 兜底)。
- **翻页主方案 = DOM 滚动**(`div[role=feed]` 语义 role 选择器,实测有效);纯协议翻页(continuation 由前端内部状态生成,响应无明文)列为待办实验。新 Maps 是预取模式:滚动先消费本地数据,耗尽才拉下一批。
- **选择器与解析 schema 走远程配置**(dom / parseSchema / scrape 三组,复用 tg-download 远程配置方案,包内默认 + 远程稀疏覆盖 + 1 小时缓存),Google 改版免发版生效。
- **失败不静默**:选择器/解析/schema 缺失必须 UI 可见 + 上报。
- 最小服务端直连方案已实测可行(`search?tbm=map&q=` 直连,未登录可访问)——云端路线(014)可复用该结论。
