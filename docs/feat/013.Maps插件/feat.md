# 013 · Maps 插件

## 功能目标

复刻竞品 G Maps Extractor v2.5.1 的完整功能面:浏览器插件跑在 Google Maps 页面上,把搜索结果商家、评论、照片、Email/社媒链接采集为结构化数据并导出,批量任务面板实现无人值守自动化,账号/配额体系支撑订阅变现。验收基准 = 功能面对齐竞品 v2.5.1(已拍板的架构差异除外,见「已拍板差异」)。

## 已拍板差异(对齐竞品时的例外)

以下实现方式与竞品不同,已经 hydra 拍板(证据:`@references/竞品逆向/11-复刻问题清单与决策.md`):

1. 不强制 Google 登录即可使用核心采集;需要配额时用自有账号/凭证体系(007/003 域)。
2. 页面定位与数据解析规则可远程更新，降低 Google 页面改版后的恢复成本。
3. 批量任务进度持久保存，浏览器后台重启后继续调度。
4. Email/社媒补全服务端自研(官网爬取 + 外链解析),不依赖第三方后端。
5. 不上 Chrome Web Store;目标 Edge Add-ons + Firefox AMO。

## 业务流程

### 官网分发

- 用户直接从官网免费下载 ZIP，无需先购买套餐；付费权益按登录账号识别。
- 官网提供分浏览器的图文安装教程，使用 MapsGrab 真实截图，图片可点击查看大图。
- Chrome、Edge、Brave 等 Chromium 浏览器解压 ZIP 后，在扩展管理页开启开发者模式并加载解压目录。
- Firefox 使用独立 ZIP，通过调试页临时加载；浏览器重启后需再次加载，下载按钮与教程必须明确此限制。
- 更新时下载新版 ZIP，替换原目录文件并重新加载。官网不提供商店安装入口或自动更新承诺。

### 单次采集权益

| 采集类型 | Free | Pro | Business |
| --- | --- | --- | --- |
| 搜索与保存列表 | 10 | 99,999 | 99,999 |
| 普通单店评论 | 20 | 250 | 2,500 |
| 单店照片与视频 | 10 | 100 | 1,000 |

按 MapsGrab 有效订阅选择单次上限；匿名、无订阅或订阅过期按 Free。每次开始或重采时，本次上限取单次权益与可用月余额的较小值。批量评论改用任务内的每店自定义目标（默认 300），再受月余额限制，不套用普通单店评论上限。

月余额为零时不发起 Google 采集，显示额度用尽提示；已有结果仍可导出。记录数在采集完成时统一计入月使用量，补全不重复计量；暂停后继续属于同一次采集。

跨端权益与执行边界见 [采集与批量技术合同](tech-采集与批量.md)。

### 主流程:搜索采集(用户视角)

1. 用户在 Maps 搜索(如 `coffee in manhattan`),面板以待命态出现在页面。
2. 点 **Start Extracting**:面板进入采集中态(实时计数 + Pause);插件按固定节奏(默认 8 秒,可调 5–10 秒)自动滚动结果列表,拦截 Maps 内部响应并解析出商家行,去重后累计。
3. 列表到底（出现结束提示）或达到本次采集上限时自动完成。
4. 完成态提供 **Export N · 格式** 与 **Reset**；开启自动下载时完成即下载。Email/社媒补全期间先显示补全进度，结束后再导出。
5. 月配额用尽(≥100%)时禁止开始,提示「已用完本期额度」并引导订阅页。

异常:结果不足 2 条时直接完成；批量模式连续 90 秒无进展进入重试或跳过；选择器或解析失败必须显示友好错误。细节:`@references/A1-地图搜索抓取.md`。

### 评论子流程

Place 详情页 → 同屏 **Reviews & Photos** 区域 → 点击 Reviews → 在新标签打开该地点的 Maps 页作为评论工作页，翻页采集 → 达到本次上限、不足一页或没有更多页面时完成 → 导出 11 列。采集中可导出已有结果；Google 中断时显示提前停止并保留结果，没有评论时显示空态。终态可 Reset 重采；检查新额度期间禁用导出与重采并保留旧结果。`@references/A2-评论抓取.md`

### 照片子流程

同一区域点击 Photos → 打开原生照片图库并翻页 → 过滤街景 → 达到本次上限或没有更多媒体时完成。导出保留 **Photo URL**、**Video URL** 两列，同一媒体同时带照片与视频地址时仍计一条；三种导出格式保持同一字段。采集与重采操作遵循上述工作页规则。`@references/A3-照片抓取.md`

### Email / 社媒补全(采集中的可选增强)

设置中勾选 Extract email address / Extract social medias(Pro 字段)→ 采集完成后由服务端补全 → 写入 Email / Social Medias 列并供导出使用。补全失败不阻断导出或批量任务推进。`@references/A4-Email与社媒补全.md`

### 批量任务流程

Dashboard 输入任务名及关键词或评论 URL（Maps 地点链接或 Google 评论链接），移除空行与重复项后，每 500 条拆分为一个任务。**Create Task** 仅保存；**Start Extracting** 保存后启动首个任务，拆分时按钮明确提示只启动首个，其余任务从 **Task History → Start** 启动。

单个任务内逐项开页采集，完成或卡死处理后自动切换下一项并导出结果。工作页面板显示只读批量任务条、当前序号与总条数，并可返回 Dashboard 查看进度。暂停不消耗本次尝试；已完成任务可 Run again，重跑前按全部条目检查额度。同一时间只运行一个任务，两类任务合计最多保存 150 个；状态持久保存，暂停、后台重启或工作页关闭后的恢复沿用同一任务。`@references/A6-批量任务面板.md`

### 列表模式流程

打开列表形态页（保存列表或搜索侧栏列表）→ 开始后**自动逐项**打开详情采集 → 滚动加载列表 → 到底或达到本次上限时完成。`@references/A7-保存列表抓取.md`

## 界面与操作逻辑

### 采集面板

| 状态 | 元素 | 行为 |
| --- | --- | --- |
| 待命 | Ready、Start Extracting、停靠切换 | 未搜索时提示先搜索；开始前重新检查额度 |
| 采集中 | 进度环与已采 / 本次上限、Export、Pause | 可导出已有结果；Pause 暂停 |
| 暂停 | Paused 与当前条数、Export、Resume | 保留结果，Resume 继续同一次采集 |
| 完成 | Complete、结束原因、Export、Reset | 导出或重置回待命 |
| 补全中 | 网站补全进度 | Export 与 Reset 等待补全结束 |
| 额度用尽 | 月度已用 / 总量、升级卡、Check again | 阻止新采集；复查仍用尽给出回执，恢复额度后解锁 |
| 原因提示 | 未搜索、解析失败、Google 中断、地点无法识别或打开失败 | 提示可采取的动作，下次成功操作时清除 |

导出按钮显示当前格式，下载后在按钮内短暂显示 **Exported**。停靠方向可切换，搜索与列表默认左侧，Place 详情默认右侧。批量模式在面板内显示只读任务条 **Bulk task · 当前项 / 总项 · Dashboard**，点击返回对应类型任务页。

视觉、交互与动效参照 [Atlas Field 设计稿](../../design/extension/README.md)，通用合同入口见 [design.md §0](../../references/specs/design.md#0--总览)。页内面板使用系统字体与等宽数字，动效服从系统减弱动态效果偏好。

### Place 详情与工作页面板

商家采集区与 Reviews & Photos 区同屏保留。点击评论或照片后显示已在新标签采集的回执，入口仍可再次使用，稍后恢复就绪；无法识别地点或打开失败时显示对应原因。

评论、照片的实时计数、导出和重采均在独立工作页，固定左侧：

| 状态 | 显示与操作 |
| --- | --- |
| 采集中 | 已采 / 本次上限；非空结果可导出 |
| 完成 | 达上限或到底；Export 与 Reset |
| 提前停止 | Google 中断说明；保留已采结果，非空时可 Export，可 Reset |
| 空结果 | 无评论 / 无照片说明；隐藏 Export，允许 Reset |
| 额度用尽 | 升级卡与 Check again，隐藏重复 Reset；已有结果仍可导出 |
| 检查额度 | Check again 显示等待，Export 与重采暂不可用；仍用尽时显示回执 |

### 批量任务面板（Dashboard）

- 两类工具：Keywords 与 Review URLs；各自保留本页草稿，创建与历史分开显示。
- 新建表单：任务名、关键词或 URL 多行输入、去空行与保序去重计数、拆分预览、Create task、Start Extracting 与 Clear；评论任务另有每店目标。卡死重试次数只读，并链接到设置页修改。
- 历史按类型过滤，行内保留 View 与主操作，More 菜单收纳复制全部 / 已完成 / 未完成及删除。删除使用站内确认；运行中删除明确说明将停止任务并关闭工作页，已下载文件保留。
- 主操作按状态显示 Start / Pause / Resume / Run again。详情显示当前项、进度与条目表；离开详情返回历史时，任务继续在后台运行。
- 两类合计最多 150 个任务；其他任务运行中时，新任务可保存并提示尚未启动。启动与重跑均检查额度，重跑按全量条目估算。

### Popup

品牌头显示 MapsGrab、已登录账号的 Free / Pro / Business 套餐徽章、Settings 与 14 语言切换。正文提供 Open Google Maps 和两类批量入口；页脚提供 Help & FAQ、Contact support 与版本号。打开时记录使用行为。

| 账号状态 | 显示与操作 |
| --- | --- |
| 访客 | Guest 与 Sign in，打开官网身份确认流程 |
| 登录中 | 加载反馈与在新标签继续的提示，等待期间禁用登录按钮，结束后复位 |
| 已登录 | 账号显示名或邮箱与 Sign out；任意界面登出后即时返回访客态 |

| 用量状态 | 显示与操作 |
| --- | --- |
| 加载中 | 用量占位 |
| 不可用 | 错误说明与 Retry |
| 正常 | 已用 / 总量、进度与下次重置日期 |
| 接近上限（≥80%） | 预警颜色与剩余额度提示 |
| 用尽 | 升级成为主操作，地图入口仍可打开但采集受额度限制 |

登录变化即时刷新账号与用量。购买、升级与订阅管理统一通过官网入口，购买范围遵循 [Pricing 需求](../011.Pricing页/feat.md)。

### 设置页（Options）

导航按采集、导出、自动化、外观分区，即改即存；页头与修改行显示 Saving / Saved，失败回滚到仍生效的值并提示重试。

- 采集：间隔五档（5/6/8/9/10 秒，默认 8），Email 与社媒补全开关。
- 导出：CSV / JSON / XLSX 三选、36 列六组选择与组内半选、12 列 Pro 标记、随设置更新的样例预览。免费用户可选择 Pro 列，实际导出按权益过滤；允许字段全空，预览说明没有选择列。
- 自动化：完成后自动下载与目录说明，卡死重试次数 0–9（默认 1）；Drive / HubSpot 沿用 A10 未决边界和现有不可用占位。
- 外观：跟随系统 / 亮色 / 暗色，以及 14 语言选择。主题与语言即时同步到 Popup、Dashboard 和页内面板；导出格式同步到预览与面板按钮。
- 插件页面打包 Plus Jakarta Sans / Azeret Mono；隐私政策链接到官网。

## 非功能性需求

- **拟人化节奏**:滚动动画随机 1.5–3.5 秒;轮询间隔在设定档位上随机抖动;所有节奏参数可被远程配置调整。
- **抗改版**:页面定位、解析、导出与节奏规则可远程更新，失败可见；用户显式偏好优先于远程默认值。实现边界见 [采集与批量技术合同](tech-采集与批量.md)。
- **后台生命周期**：批量任务进度持久保存，后台重启后可恢复。
- **兼容**:Chrome / Edge(Chromium)全量;Firefox MV3 事件页做调度平台分支。
- **网络地区**：Google 把访问判定为中国大陆时会把评论请求转往其区域域名，评论采集在这类网络下不可用，照片按 Google 实际落地页继续采集。
- **隐私红线**:上报字段按 009 域脱敏口径审查;不发送 Cookie/令牌/完整下载直链。
- **性能**:单批响应在 progress 阶段即消费;大响应不阻塞页面。
