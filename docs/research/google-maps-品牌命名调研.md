# Google Maps 产品线品牌命名调研

> 结论:品牌定 **MapsGrab**,产品全称 **"MapsGrab — Google Maps Scraper & Extractor"**。2026-08-30 hydra 拍板。
> 候选对比过程与词频 / 域名数据如下,数据为 2026-08-30 实查。

## 1 · 类目词:scraper > extractor >> exporter

| 词 | Google Trends 均值(全球,近 12 个月) | Google 精确匹配结果量 | 头部玩家 |
| --- | --- | --- | --- |
| google maps scraper | ~60(峰值 100) | ~148,000 | Apify、Outscraper、Brightdata、mapsscraper.com、scrap.io |
| google maps extractor | ~18(峰值 72) | ~27,300 | G Maps Extractor(gmapsextractor.com,主竞品)、GMPlus、omkar.cloud |
| google maps exporter | ~8 | ~161 | 全是 KML / 地图文件导出插件,非同类产品 |

- **exporter 直接排除**:地图语境下 "exporter" 语义 = 导出 KML/KMZ 地图文件,与抓取商机数据是两个需求,会被语义分流。
- **scraper 是最大词但头部拥挤**;extractor 是第二词、竞争小一档。
- **类目词不做二选一**:竞品先例(gmapsextractor.com 商店标题 "Google Maps Scraper: Free & Easy to Use | G Maps Extractor"、gmapsscraper.io "Google Maps Scraper & Extractor")都是**双词 SEO 覆盖**。故全称采用 "MapsGrab — Google Maps Scraper & Extractor"。

## 2 · 域名格局(RDAP + whois 实查,2026-08-30)

| 系列 | 状态 |
| --- | --- |
| gmapextractor.* | .com 已注册且 301 → gmapsextractor.com(竞品持有);.dev/.ai/.tools 可注册 |
| gmapexporter.* | 全 TLD 可注册(但词已排除) |
| gmapscraper.* | .com/.dev/.tools 已被抢注,仅 .ai 可注册 |
| gmapsscraper.* | .com/.ai 已注册;.dev/.tools 可注册 |
| mapsscraper.* | .com/.ai 已注册(竞品在用);.dev/.tools 可注册 |
| mapsextractor.* / mapsexporter.* | .com 均已注册;其余 TLD 可注册 |
| 通用组合词 .com(mapleadextractor / mapharvest / grabmaps / mapsgrabber / mapleadscraper / pluckmap) | 全部已注册 |
| **mapsgrab.com / mapspull.com / mappluck.com** | **可注册** |

规律:词越热域名被抢注越狠(scraper 系几乎无好域名残留);通用词组合 .com 基本无空位;动词型短品牌尚有 .com 空间。

## 3 · 否决 "GMap Extractor" 的理由

1. **品牌混淆**:与主竞品 "G Maps Extractor"(gmapsextractor.com,013 域逆向对象)几乎无法区分,且对方持有 `gmapextractor.com` 做 301 截流。
2. **商标风险**:"GMap" 历史上是 Google Maps API 的旧称,品牌主词蹭 Google 有商店下架的隐性风险(商店页描述里写 "Google Maps" 是类目惯例,不受此限)。

## 4 · 拍板结果

- **品牌**:MapsGrab;主域名 **mapsgrab.com**(可注册,注册前以注册商实时查询为准)。
- **产品全称 / SEO 标题**:"MapsGrab — Google Maps Scraper & Extractor",双类目词覆盖流量。
- 备用域名(mapsgrab.dev 等)未查;如需防御性注册另行决策。
