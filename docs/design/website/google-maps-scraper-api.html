            Capabilities
            
What the Scraper API returns

            

              One request per keyword and location, answered with the same structured fields the extension exports — built for
              your own applications.
            

          


          

            

              
              
Search by keyword and location

              
Send a keyword with an optional location bias and receive the businesses a Google Maps search would show.

            

            

              
              
The 36-column business schema

              
Name, categories, full address, phone, website, rating and review count, opening hours, latitude / longitude, Place ID, CID, and more.

            

            

              
              
Email and social enrichment

              
Responses include email addresses and social profiles found on each business website — no separate enrichment step.

            

            

              
              
Clean JSON responses

              
Structured, predictable field names ready for your CRM, spreadsheet pipeline, or backend — no HTML to parse.

            

            

              
              
Public data only

              
The API returns only what is publicly displayed on Google Maps — the same details any visitor can read.

            

            

              
              
Same engine as the extension

              
The API is backed by the MapsGrab extraction engine, tuned against the current Google Maps interface and updated remotely when Google changes.

            Reference
            
Request in, JSON out

            

              Authenticate with Authorization: Bearer YOUR_API_KEY and send a JSON body. Fields that
              can't be confirmed come back as null — never as empty strings.
            

          


          

            

              

                
                

                  
Request

                  POST/v1/search
                

              

              

                

                  
                    
ParameterTypeDescription

                  
                  
                    
qrequiredstringWhat to search for — a business type plus a place, e.g. coffee shop in Portland.

                    
pagesintegerResult pages to collect, 1–10. Each page adds up to 20 places, returned together in one response; collection stops early when a page has no new places. Default 1.

                    
hlstringLanguage for names, categories and addresses, e.g. en.

                    
llstringOptional location bias as @lat,lng,zoom. Tells Maps where to search — results aren't clipped to a radius.

                  
                

              

            


            

              

                
                

                  
Response

                  { places: place[] }

namestring"Ember & Oak Coffee"

                    
categoriesstring[]["Coffee shop", "Espresso bar"]

                    
place_idstring"ChIJ8Qv2kSIKlVQRq-DRw_KltL4"

                    
fidstring"0x54950a2291f60bf1:0xbeb4a5f2c3d1e0ab"

            FAQ
            
Scraper API questions

            
The short answers. Anything else, support is one email away.

            
              Contact support
            
          

          

            

              What does the Scraper API return?
              
Structured JSON with the MapsGrab 36-column business schema: name, address, phone, website, rating, review count, opening hours, coordinates, Place ID, and email / social enrichment where available.

            

            

              How do I authenticate?
              
Requests are authorized with a MapsGrab API key sent as a bearer token. Keys are issued per account and follow the API plans on the Pricing page, including 20 free requests per month.

            

            

              Is the data legal to collect?
              
The API only returns information that is publicly displayed on Google Maps — the same details any visitor can read. We do not access private accounts, gated content, or non-public data.

            

            

              Can I also get reviews and photos?
              
Yes — pass the fid from any Scraper API result to the Reviews API or the Photos API, using the same API key.

            

            

              How are requests counted?
              
A request is one successful API call that returns data. Usage resets on the 1st of each month and unused requests do not roll over.
