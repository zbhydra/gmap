What the MCP server exposes

Three tools over one endpoint, backed by the same extraction engine as the extension and the APIs.

Tool
search_businesses(q, pages?, hl?, ll?)

Search businesses

Keyword and location searches that return the listing details a Google Maps search would show — names, phones, ratings, hours, coordinates, Place IDs.

q
Keyword plus city, state or ZIP
pages
Result pages to collect, 1–10 · up to 20 places each
hl
Result language, e.g. en
ll
Location bias, @lat,lng,zoom
Returnsplaces · 36 fields each
Same data as the Scraper API
Tool
get_reviews(fid, sort_by?, cursor?)

Collect reviews

Ratings, review text, reviewer details, dates, and owner replies for any business your agent is investigating.

fid
From any search result
sort_by
1 relevant · 2 newest · 3 highest · 4 lowest
cursor
next_cursor from the last page; omit for the first
Returnsreviews ≤ 60 · next_cursor
Same data as the Reviews API

fid

Setup

One config block per client

Point your client at the MapsGrab endpoint and pass your API key in the Authorization header. No SDK, no local process to run.

  1. Get your API keyCopy it from Dashboard → API.
  2. Add the serverRun the command in your terminal. It registers mapsgrab over HTTP with your key in the header.
  3. Ask for Maps dataStart a session — Claude Code lists the MapsGrab tools and calls them when a prompt needs them.
Terminal 
claude mcp add --transport http mapsgrab https://mcp.mapsgrab.com/mcp \
  --header "Authorization: Bearer YOUR_API_KEY"

}

Auth & data

One key in one header. Public data only.

Every call to the MCP endpoint is authorized with your MapsGrab API key, and every result comes from what Google Maps shows publicly.

Request Key verified

POST /mcp HTTP/1.1

Host: mcp.mapsgrab.com

Authorization: Bearer ••••••••••••••••••••

Content-Type: application/json

Accept: application/json, text/event-stream

{"jsonrpc": "2.0", "id": 7, "method": "tools/call",

"params": {"name": "get_reviews",

"arguments": {"fid": "0x5495…e0ab", "sort_by": 2}}}

Response

200 OK · application/json

{"jsonrpc": "2.0", "id": 7, "result": {"structuredContent": {

"reviews": [{"rating": 5, "text": "Best cortado on Division…", … }, …],

"next_cursor": "CAESBkVnSUlDZw…"}}}

One key, one header

Calls carry your MapsGrab API key as a bearer token — the same key that covers the Scraper, Reviews and Photos APIs.

Retrieval only

The tools search and read. None of them change your MapsGrab account or anything on Google Maps.

Keep keys out of repos

Use VS Code's secure input or an environment variable for Codex, so the key never sits in a shared config file.

Public data only

The server returns only information publicly displayed on Google Maps — the same details any visitor can read.

What is the MapsGrab MCP server?

It is an MCP (Model Context Protocol) server that lets AI agents query live Google Maps data — business search, reviews, and photos — through the same MapsGrab extraction engine used by the extension and the APIs.

Which clients can connect?

Any MCP-compatible client: Claude Code, Cursor, VS Code, Codex, MCP Inspector, and others. Connection is a standard config block pointing at the MapsGrab MCP endpoint with your API key.

How is it authenticated?

With a MapsGrab API key passed as a bearer token — the same key the API plans on the Pricing page cover, including the free monthly request quota.

What data can my agent retrieve?

Business search results with the 36-column schema, review threads with ratings and owner replies, and public photo URL lists per business.

How are tool calls counted?

Tool calls run on the MapsGrab API, so each one that returns data counts as a request against your monthly API quota. Usage resets on the 1st and unused requests do not roll over.
