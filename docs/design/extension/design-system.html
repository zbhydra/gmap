Map in, data out

Every surface tells one story: pin → scan → rows → export. Icons, empty states and motion all follow that order.

Instrument, not poster

Dense, calm, tabular. Numbers are monospaced and aligned; gradients only mark the brand and progress.

Every state is legible

State never relies on color alone: dots, pause bars, checks and crosses, plus words. Errors say what to do next.

Motion reports

Things move because something changed: a count rolled, a run started, a file left. Loops live only while work runs.

A quiet guest

Inside Google Maps the panel uses system fonts, transform-only motion and no blur — it never slows the host page.

01 · Color

One action color. States you can read without color.

Values are the website’s landed tokens. Each semantic token resolves through light-dark(); the theme follows the system unless the user picks Light or Dark in Settings (L11).

Primitives

Semantic tokens light / dark

Contrast, measured

Ratios are computed in the browser from the resolved tokens of both themes (soft fills composited over --surface). Text pairs need 4.5:1; the switch track is a non-text control and needs 3:1.

Pair Light Dark Used for

--text-3 passes on --surface, --surface-2 and --bg-2 only — never place it on --surface-3 (the segmented track and skeletons).

04 · Motion

Motion reports what just happened.

Four tiers, four curves. Rich on the popup, dashboard and settings; restrained inside Google Maps. Every effect has a reduced-motion end state — flip Motion → Reduced in the state dock to check.

Tier Duration Curve Used for
T1 · micro --dur-1 120 · --dur-2 180 --ease-out Press scale, hover fills, focus, color changes
T2 · transition --dur-3 280 --ease-emph · --ease-spring Menus, tabs, segmented thumb, label morphs, dialogs, toasts
T3 · entrance --dur-4 560 · --dur-5 900 --ease-out Popup choreography (stagger 40), list rows, count roll, progress advance
Live loop --dur-live 1600 · --dur-beam 1800 linear · --ease-in-out Pulse dot, ring scan, progress beam — only while a run is active

12 · Surfaces · In-page panel

A quiet guest inside Google Maps.

panel.css is self-contained: :host { all: initial }, its own copy of the color tokens, system fonts, transform/opacity motion only. Width grows from 236 to 280px so the progress ring, the two-line readout and a one-line “Export 48 places · CSV” fit without wrapping.
