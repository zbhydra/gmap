Twelve changes the designs follow.

From logic.md §9. They are drawn into the prototypes now and synced back to the 013 feat when implemented.

  1. L1Run progress, N / limitProgress ring in the panel; paused reads “Paused · N places”.Panel
  2. L2Errors by reasonNot searched, parse failed, no reviews, Google error, place not identified — each with a next step.Panel
  3. L3Upgrade entry when outAlways shown at the limit; Start re-checks the quota every time.Panel
  4. L4Reviews & photos entries“Collecting in a new tab”, reopen, then reset after a few seconds.Panel · place
  5. L5Near-limit usage, sign-in loading≥ 80% gets its own state; signing in shows a spinner.Popup
  6. L6One main action per taskView + Start / Resume; copies and Delete in More; in-page confirm.Dashboard
  7. L7Start · Resume · Run againOne verb per state, and completed tasks can run again.Dashboard
  8. L8Back doesn’t pauseTasks keep running in the background; detail can be reopened anytime.Dashboard
  9. L9Retries live in SettingsThe form shows the current value read-only with a link.Dashboard · Settings
  10. L10Bundled fonts, system panelPlus Jakarta Sans + Azeret Mono in extension pages; system fonts in the panel.All
  11. L11Theme settingSystem, light or dark — shared by every surface, the panel follows.Settings · All
  12. L12Docs follow the designUnbuilt feat items are removed; the new design is the contract.Docs
Foundation · phase A

Shared files every page builds on.

Plain HTML, native CSS and JS — no build, no CDN. Pages keep their private styles in assets/css/pages/ and scripts in assets/js/pages/.

File Role
css/tokens.cssAtlas Field tokens: color (light-dark), type, space, radii, shadow, motion
css/base.cssFonts, reset, type utilities, layout primitives, icons
css/components.cssShared components for popup, dashboard and settings
css/motion.cssKeyframes, entrance choreography, reveal, reduced motion
css/panel.cssSelf-contained Shadow DOM stylesheet for the Maps panel
css/proto.cssPrototype only: state dock, stage, browser frame, Maps mock
js/theme.js · motion.js · ui.jsTheme boot + API, motion runtime, component behaviors
js/proto.jsPrototype only: Proto.states, flows, Maps host mock
img/icons.svg · logo.svgOne-stroke icon sprite and the brand mark
